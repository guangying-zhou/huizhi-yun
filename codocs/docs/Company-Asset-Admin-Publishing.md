# 组织资产管理员功能上线说明

系统管理员在组织资产任意分类点击「快速发布」，选择部门、目录和文档后直接发布。源部门文档保持可编辑，组织资产生成独立只读副本；不走审批、不发送企业微信通知。失败后在同一弹窗重试复用操作编号，避免重复发布；关闭并重新发起属于新操作。

副本写入使用 Foundation 的 `forbidOverwrite` 选项，由适配层按 OSS 或 S3/R2 选择请求头，避免向 OSS 同时发送不兼容的 S3 条件而导致 400。目标路径由 runtime 预留，重试时校验操作编号、源文档标识及已复制对象的 ETag 和长度；OSS bucket 需保持未启用版本控制，才能使用 OSS 提供的防覆盖条件。

普通用户不显示组织资产「发布记录」，对应 API 也拒绝读取。管理员可查看审批发布记录或快速发布的操作人和时间。

管理员选中文档后可打开「查看记录」，按 UTC 日期筛选、分页和导出 CSV。记录从功能启用后开始，以成功准备正文或 PDF 数据的请求为准，不推断实际阅读完成、时长或历史访问。PDF 元数据查询不记数，画布阅读器的一次完整数据加载记录一次，翻页/缩放不重复记数。记录按 OSS 路径归属，移动文档前的记录仍保留在原路径。CSV 包含 Console 当前中文姓名、用户 UID、UTC 时间与文档路径；未匹配姓名明确标注并保留 UID，目录故障时提示重试；超过 50,000 条须缩小筛选范围。

已发布公司/部门文档的「复制链接」生成 16 位短码，例如 `/codocs/s/AbCd01234567_-xy`，历史文档无需补建 UUID。短链接保持当前租户域名、登录权限、水印和查看记录；原长链接继续可用。复制或打开短链接均不发送企业微信通知。映射按原 OSS 路径保存，文档移动后应重新复制新位置的链接，归档或删除后原链接不再能访问正文。

## 部署顺序

1. 在各租户的 Codocs runtime 数据库执行 [快速发布操作表](./company_asset_quick_publish.sql)、[查看记录表](./migrations/20260910_company_asset_access_records.sql) 和 [短链接映射表](./migrations/20260910_published_asset_links.sql)。前两张表已上线的租户只需新增短链接表。新建库使用更新后的 `codocs_schema.sql`。
2. 按正常版本发布流程更新 data-runtime，确认具备 quick-publish prepare/complete、access-records record/list/export 和 published-asset-links create/resolve 合同；不要覆盖已发布的不可变版本包。
3. 重新登记 Codocs 应用 manifest，并通过 Platform 正常策略发布流程让管理员角色取得新增的显式 `codocs:company:export` grant。前后端统一消费 Foundation 权限；不通过浏览器角色字段判断管理员，也不把 `company:admin` 隐式视为 export。
4. 更新 Codocs。新版本在组织资产预览返回前写入查看记录，若缺表或 runtime 不可用会返回 503，因此不得先部署 Codocs 再补依赖。

## 验收

已发布 Markdown 正文禁止文字选择、拖拽及正文复制事件，代码块不显示复制按钮；公司/部门列表预览、长短链接阅读页和已发布 UUID 阅读入口一致。滚动、正文链接及页面“复制链接”继续可用，普通编辑文档不受影响。

已发布 PDF 使用画布逐页显示，不创建文字选择层，支持翻页、缩放和滚动。PDF 数据通过同源原预览 API 读取，保持登录与查看记录，不依赖 OSS CORS。PDF.js worker、中文 CMap、标准字体及 WASM 随 Codocs 静态资源发布，无需外部 CDN。

- 管理员快速发布后，原部门文档仍可编辑，目标分类出现只读副本和直达链接；查看直接发布记录能看到操作人和时间，不出现审批记录或企业微信通知。
- 普通用户看不到快速发布、发布记录或查看记录入口，直接调用对应管理员 API 返回 403。
- 普通用户成功预览后，管理员在相同路径的查看记录中看到用户和 UTC 时间；分页、日期筛选及 CSV 导出一致。没有显式 export grant 时隐藏导出按钮并拒绝导出 API。
- 缺权限、缺文件和仅加载元数据的请求不新增查看记录；查看记录服务故障返回可重试 503。
- CSV 中真实中文姓名与 Console 当前目录一致，未匹配用户保留 UID；短链接可在桌面和手机打开并沿用预览水印和查看记录，无权限账号不能通过短码获得正文。
