# DEBUG REPORT — 2026-07-20 使用指南菜单位置

## 状态

DONE

## 现象

`app/config/permissions.ts` 和 `app.manifest.json` 已声明“使用指南”资源与菜单，但生产页面左侧业务菜单没有显示该项，页面标题栏右侧仍显示问号入口。

## 根因

权限和清单配置有效。`app/layouts/default.vue` 在权限过滤完成后，主动从左侧辅助菜单中筛除了“使用指南”，再把它转换为标题栏右侧下拉菜单。因此继续调整权限资源或重新发布清单无法改变显示位置。

## 修复

- 删除布局中针对“使用指南”的提取、过滤和标题栏下拉菜单。
- 左侧辅助菜单直接使用权限过滤后的完整第二组菜单，保留配置中的“系统管理 → 使用指南”顺序。
- 保留“Markdown教程”和“Mermaid语法”为新窗口外部链接。
