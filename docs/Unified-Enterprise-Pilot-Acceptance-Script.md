## 5. 故障与恢复矩阵（INT-504）

执行方先登记注入方法、影响范围、恢复方式与责任人；只有经批准的隔离环境和既有工具可注入，不临时改代码/写故障开关，不停共享依赖。浏览器网络节流仅证明客户端迟到/丢响应，不能冒充服务端事务中断、Runtime 离线或撤权。每例保存前/后数据 revision、receipt 数、策略/任务水位与时间线；恢复后用新请求回读并再走一次受影响正常业务步骤。
