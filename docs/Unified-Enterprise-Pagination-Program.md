## 通用合同

Runtime 列表页码可选，`page=1..1000000`、`pageSize=1..100`；不带参数时保持原响应形状和旧消费者语义。显式分页返回 `items,total,page,pageSize`，越界空页但 total 真实。BFF 拒绝重复、空、非规范整数、越界、未知或与 cursor/limit 冲突的参数。权限、对象可见性、筛选、软删除均先于 COUNT/page；两者同 WHERE、只读快照、稳定唯一排序。图表/合计取完整授权集合，不由当前页 reduce。Host 展示 `共 N 条` 和 UPagination，过滤变动回第一页，身份/撤权清旧状态并拒绝迟到响应。新增路径逐 METHOD 对照拓扑；新增 query 纳入签名 permit 的完整 body 绑定。
