# 汇智云使用说明（文档与项目）

适用于 2026 年 10 月 8 日开放范围，供员工日常查文档、协同写作、跟进项目和提交工作汇报使用。

- **访问入口**：[aidcp.wiztek.cn](https://aidcp.wiztek.cn)，简短别名：[work.wiztek.cn](https://work.wiztek.cn)。建议收藏其中一个。
- **本次开放**：工作台、我的待办、工作汇报、项目、文档与通知。实际可见内容取决于本人权限。
- **暂未开放**：销售、财务、人力。

## 我要找到今天要做的事

1. 登录后进入「工作台」，查看工作入口。
2. 打开「我的待办」，查看需要本人处理的事项。
3. 打开具体事项，按页面提示处理，并确认处理结果。

项目工作项也可从「项目」下的「任务中心」查找。**打开一条通知或将其标为已读，不代表已完成待办或任务。**

## 我要找文档、写新文档或使用模板

先按用途选择空间：

| 我要找的内容 | 从哪里进入 |
| --- | --- |
| 自己整理、撰写的文档 | 「文档」→「我的空间」→「我的文档」 |
| 部门共同维护的内容 | 「文档」→「部门空间」→「部门文档」 |
| 公司制度、通知公告等公共资料 | 「文档」→「公司空间」，选择相应栏目 |
| 文档模板 | 「文档」→「公司空间」→「文档模板」 |
| 某个项目的资料 | 「项目」→「项目文档」 |

**新建个人或部门文档：**

1. 进入「我的文档」或有权编辑的「部门文档」，选择存放位置。
2. 点击「新建文档」。
3. 填写「文档名称」，点击「创建」。
4. 打开文档编写正文，离开前确认保存或同步状态。

**使用模板：**先在「文档模板」中查看适用模板，再在个人或部门空间新建文档，参照模板填写。不要直接把共享模板原文改成自己的业务内容。

## 我要让同事一起写，或只让同事阅读

文档创建者可管理共享；没有共享入口时，请联系创建者处理。

1. 在文档列表中打开目标文档的操作菜单，选择「共享」；部门文档入口为「共享/提醒」。
2. 选择同事。
3. 选择「读写」或「只读」。需要时填写附言。
4. 点击「共享」或「共享/提醒」，确认操作成功。

在编辑器中，也可从更多菜单进入「共享」侧栏：填写「用户名」，选择「只读」或「可编辑」，点击「添加共享」。「可编辑」与列表共享弹窗中的「读写」表示相同的协作意图。

注意：

- **同部门成员与负责人默认可编辑本部门的普通协作文档**，无需逐人共享。对本部门成员使用「共享/提醒」主要用于提醒，不会另加一条共享记录。
- 文档被设为只读、工作汇报已上报等情况下，仍受对应限制。
- 只读文档与项目文档的编辑器共享入口仅支持只读共享。项目编辑权限请联系项目负责人确认。
- 转发链接不会自动赋予权限。接收人打不开时，请检查共享对象或所属部门、项目权限。

## 我要和同事同时编辑

个人与部门文档支持多人实时协同。先确认参与者具有编辑权限，再打开同一份文档共同编写。

1. 开始前约定各自编辑的章节，减少同时改写同一段的情况。
2. 编辑时留意顶部保存、同步状态；协同编辑会自动同步保存。
3. 离开前确认没有「未保存」或持续「保存中...」的提示。

**断线会自动重连，但不要多人同时离线大幅改写同一份文档。** 网络异常时，先暂停大段修改，保留当前页面；必要时将尚未同步的文字另存为临时备份。恢复连接后，确认同步状态和最后修改的内容，再继续协作。不要靠反复刷新或关闭页面处理未保存问题。

若出现「共享状态待核验」或暂时只能查看，先等待连接恢复；持续异常时按文末渠道反馈。

## 我要查看旧版本或对文档提意见

**查看旧版本：**在文档编辑器的更多菜单中选择「历史版本」，查看可用记录。恢复旧版本前，先与协作者确认，避免影响正在进行的修改。只读状态下，不能查看历史版本内容差异或恢复历史版本。

**提意见（页面名称为「标注」）：**

1. 在可编辑的文档中选中需要讨论的文本，打开添加标注操作。
2. 在「添加标注」窗口填写意见，点击「创建」。
3. 在侧栏「标注」中查看讨论；需要回复时点击「回复...」，填写内容后点击「发送」。

标注不等于已修改正文。只有阅读权限时，请将修改建议和文档链接发给创建者或负责人。

## 我要找项目、项目资料或推进任务

### 找项目与项目集

进入「项目总览」，通过「搜索项目...」查找项目，也可按状态、分类或项目集筛选。项目集用于归组查看项目；未归组的项目可在「未分组」中查找。

有管理权限的同事可进入「项目管理」，通过项目管理树查看项目集和项目。普通员工看不到这个管理入口时，可继续使用「项目总览」，不必申请管理权限才能开展日常工作。

### 找项目文档

1. 进入「项目文档」。
2. 从按项目集组织的列表中选择项目。
3. 在文档目录中选择需要的文档，查看内容。

出现「暂无可访问项目」或「当前没有可访问的项目文档」时，请联系项目负责人核对项目成员身份及文档范围。

### 推进项目任务

1. 进入「任务中心」。
2. 选择「我负责的」「我参与的」「我创建的」或「待我验证」，必要时再按项目筛选。
3. 打开任务，查看要求、负责人和当前状态。
4. 按页面提供的操作推进任务，确认状态更新结果。

「规划中」「待办」「执行中」「确认中」「已完成」表示不同阶段。进入「确认中」后仍需完成相应确认，不能直接视为已完成。

## 我要填写和上报工作汇报

1. 打开「工作汇报」，选择「工作日志」或「工作周报」。
2. 在左侧日历选择日期或周。
3. 点击「创建日志」或「创建周报」；已有内容时，点击「编辑日志」或「编辑周报」。
4. 填写内容，确认保存完成。

**上报后文档将设为只读，不能继续修改。** 核对无误后，回到汇报页面点击「上报」，再点击「确认上报」。页面显示「已上报」后，才算完成上报。保存草稿不等于上报；上报后需要更正，请联系负责人或管理员。

## 我要查看通知和打开通知里的内容

- 点击顶栏铃铛，打开「通知中心」。可在「全部」「未读」之间切换，也可选择「查看全部通知」。
- 收到企业微信通知后，可直接打开其中的链接；如提示登录，完成登录后再打开原链接。
- 「全部已读」只改变通知阅读状态。涉及待办、项目任务或文档处理的事项，仍需进入对应页面完成操作。

## 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 文档只能读，我需要编辑怎么办？ | 联系文档创建者，说明文档链接和修改用途，请其核对共享权限。部门文档找部门负责人；项目文档找项目负责人。只读或已上报状态可能有额外限制，不能仅靠增加共享解除。 |
| 同事能看见，我看不见怎么办？ | 先核对登录账号、所选空间及筛选条件。个人文档找创建者，部门内容找部门负责人，项目内容找项目负责人；仍无法解决再找管理员。 |
| 为什么链接能打开，却提示无权查看？ | 链接不授予权限，共享或成员权限也可能已变化。将链接和提示交给内容负责人核查。 |
| 看不到「项目管理」等菜单怎么办？ | 菜单按权限展示。日常找项目先用「项目总览」；确需管理操作时联系管理员确认职责和权限。 |
| 修改后一直未保存，或重连后内容不对怎么办？ | 暂停继续改写，保留页面及未同步文字，记录时间和提示后反馈。不要反复刷新或直接恢复历史版本。 |
| 为什么找不到销售、财务、人力？ | 这三类功能暂未开放，不属于本次员工使用范围。 |
