# 10 常见问题排查

按**客户描述的现象**索引，每条给出定位顺序。

## 10.1 访问与权限

**客户全员登录后 403 / 看不到任何应用**
1. `/admin/tenants/{code}` 看开通阶段是不是 `active`
2. License 是否 active 且已下发到该部署
3. 部署连通性是否 passed
4. 策略包版本是否卡在旧版

**个别用户 403**
1. 请客户管理员确认该用户被授予了对应应用角色
2. 确认数据范围覆盖了他要访问的对象（部门/项目/客户）
3. 若是审批、导出、关闭这类动作，确认敏感动作已**显式**授权——`admin` 不自动蕴含它们
4. 确认用户账号在企业目录中是 active

**客户说"权限改了没生效"**
1. 企业侧改完角色后需要重新登录或等策略包刷新
2. `/admin/deployments` 看该部署的 bundle 版本是否已更新
3. 若卡住，触发一次策略包重新下发

**用户已被停用但还能登录**
按 `吊销条目 → 吊销快照 → 快照分发目标` 逐层追，看断在哪一层（见 [08 章 8.5](./08-部署与运行诊断.md#85-策略包与吊销)）。

## 10.2 开通与订阅

**开通编排卡在某一步**
看页面右上角的"推荐下一步"。五步的前置依赖是硬性的：没有订阅关系就配不了 deployment，没有 deployment 就签不了 License。

**连通性通过了但客户说还没开通**
正常。连通性通过 ≠ 开通完成。还要 License active + License 下发关系 active，三者齐了才过发布闸门。

**客户买了某应用但菜单里没有**
1. 订阅计划里是否真的包含这个应用
2. 订阅是否 active
3. License 的 capability 是否包含这个应用
4. 用户是否被授予了该应用的任一角色

**订单确认到账后订阅没激活**
1. 检查订单状态流转记录，确认到账动作是否真的提交成功
2. 确认到账日期填写正确——订阅按到账日期算起
3. 不要新建订单绕过，会造成期限重复计算

**续订后客户到期还是失效了**
订阅续了但 License 没重签。检查 License 到期日是否同步更新并重新下发。

## 10.3 版本与发布

**Manifest 审核通过但权限清单没变**
注册请求 approved → 是否已物化 → 应用的最新 Manifest 指针是否更新 → 租户策略包是否重新下发。四步逐一确认。

**版本漂移告警**
- `app_version` 落后 → 客户未升级，通知升级
- `manifest_hash` 不一致 → **优先处理**，代码与登记 Manifest 不符，先查发布记录
- `sdk_version` 不兼容 → 按兼容矩阵确认，可能需要同时升级 Foundation

**应用启动了但平台没收到 Manifest**
应用启动只做版本报到和心跳，**不会**触发 Manifest 注册。注册必须走发布流程或专用 CLI/API。

## 10.4 跨应用调用

**日志里出现 `insufficient_scope`**
跨应用服务授权（Console grant）缺失或漂移。修复 grant，**不要**删掉精确 scope、吞掉 403 或退回宽 scope。

**日志里出现 `console_service_token_grant_inactive`**
同上，grant 存在但状态不是 active。

**某个后台任务（worker）一直失败**
Console grant 需要同时覆盖 `data-runtime` 和 `tenant-runtime` 两个 audience。只配一个会在运行时失败。发布前应用实际 service client 对全部组合 scope 做令牌签发探测。

**跨应用调用返回 502**
不正常。认证失败应该是 401，授权不匹配应该是 403。502 通常意味着中间层把下游错误吞掉了，需要研发介入查具体链路。

## 10.5 心跳与运行

**心跳中断**
1. 客户侧服务是否在运行
2. 网络/防火墙是否变更
3. runtime 地址配置是否被改过
4. 托管云部署看对应 Worker 状态

**功能时好时坏**
可能是多部署环境不一致（一个部署升级了、另一个没有）。在 `/admin/deployments` 看该租户的所有部署版本是否一致。

## 10.6 升级到研发的判断标准

以下情况不要自己继续试，直接升级：

- `manifest_hash` 不一致且发布记录查不到对应变更（可能是私自改动）
- 跨应用调用返回 502，或错误信息里出现内部地址、Token 片段
- 审计日志显示有操作但客户侧完全没有对应效果
- 同一问题在多个租户同时出现
- 涉及数据正确性（金额、权限范围）的疑问

升级时带上：租户编码、部署编码、发生时间窗口、完整错误信息、已排查步骤。
