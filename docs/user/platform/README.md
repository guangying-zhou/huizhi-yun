# 汇智云平台运营管理手册

面向**汇智云运营方**（平台管理员、交付实施、商务、支持）的操作手册。
入口：Platform 运营控制台 `/admin`（默认端口 3011）。

> 企业客户自己使用的功能不在本手册，见 [`../tenant/README.md`](../tenant/README.md)。

## 三条最常走的路径

**新客户上线**：06 租户建档 → 07 下单开通 → 05 确认套餐能力 → 08 配置部署并做连通性检查 → 06 通过发布闸门。

**新应用上架**：03 提交并审核 Manifest → 04 登记 Release → 05 把应用挂进订阅计划 → 06 给目标租户开通。

**客户报障**：10 按现象定位 → 08 看部署与心跳 → 09 查审计日志 → 必要时 04 回滚版本。
