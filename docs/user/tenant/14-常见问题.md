# 14 常见问题

按现象查找。找不到的问题联系企业管理员，管理员再联系汇智云支持。

## 14.1 登录与访问

**打不开系统 / 页面一直转圈**
1. 确认网址正确（问同事要一次）
2. 换个浏览器或用无痕窗口试
3. 同事也打不开 → 联系企业管理员；只有你打不开 → 清缓存重试

**登录后看不到任何应用**
公司可能还没完成开通，或你还没被授权。找企业管理员确认。

### 企业资格与应用入口

应用入口会把企业资格、模块就绪状态和个人权限分开提示。先记录提示标题或错误码，再按下表处理；不要通过反复切换角色或修改旧套餐来绕过。

| 提示/错误码 | 含义 | 员工怎么做 | 管理员怎么做 |
| --- | --- | --- | --- |
| 企业功能资格暂不可用 / `enterprise_entitlement_inactive` | 企业资格未生效、已停用或已过期 | 联系企业管理员 | 联系平台运营核对资格或续期；不通过增加人员角色绕过 |
| 模块尚未配置 / `module_not_configured` | 企业具备资格，但独立模块尚未完成企业配置 | 联系企业管理员 | 在企业控制台完成模块配置；这不是购买限制 |
| 模块尚未部署 / `module_not_deployed` | 企业具备资格，但模块未部署 | 联系企业管理员 | 联系 IT 或实施完成部署、连通性检查 |
| 访问权限不足 / `person_permission_denied` 或 403 | 当前人员缺岗位角色、敏感动作或对象范围 | 联系企业管理员并说明要访问的对象 | 用[成员权限诊断](./05-角色与权限管理.md#55-两个诊断工具)补最小必要角色/范围 |
| 服务暂不可用 / `service_unavailable` 或 503 | 应用、Console 或数据服务暂时不可用 | 稍后重试 | 检查运行状态；持续出现时联系汇智云支持 |

企业全量功能资格只说明企业能使用全量功能，岗位角色说明员工能做什么，对象范围说明员工能处理什么数据。三者不可互相替代。

**用企业微信/钉钉登录失败**
找企业管理员检查集成配置和凭证是否过期。

**总是被要求重新登录**
可能是会话超时设置较短，或多设备登录冲突。找管理员确认系统参数里的会话配置。

## 14.2 权限（最常见）

**能进应用但页面显示 403**
缺角色或缺数据范围。找管理员，让他用「检查员工是否有某项权限」诊断（见 [05 章 5.5](./05-角色与权限管理.md#55-两个诊断工具)），直接就能看出缺什么。

**能看列表但看不到某个部门/项目的数据**
数据范围没覆盖那个部门/项目。角色对了，范围不对。

**能看但不能审批 / 不能导出 / 不能关闭**
审批、确认、导出、关闭、发布属于敏感动作，**必须单独授权**，不会因为有"管理员"角色就自动获得。找管理员单独授予。

**管理员说给我配好了，但还是不行**
重新登录一次。权限刷新需要新会话。

**同事有的功能我没有，我们岗位一样**
让管理员在「成员权限」页对比你们两个人的有效角色，差在哪一眼就能看出来。

**我要切成管理员角色才能操作**
不正常。系统会合并你的全部有效授权，不需要切换角色获得日常权限。找管理员确认配置。

## 14.3 待办与审批

**待办标记已读了还在**
正常。待办的关闭条件是**来源业务办完**，不是你看过。

**该我审的单子没出现在"我的任务"**
1. 让发起人确认流程真的走到了你这个节点
2. 确认你有 `workflow:approver` 角色
3. 确认审批路由规则指向的是你

**能看到任务但按钮是灰的**
任务不是分配给你的，或状态不是"待处理"（可能已被处理或已撤回）。

**为什么我不能审批这张单子**
可能命中职责冲突规则（比如你是提交人，不能自审）。让管理员用「检查单据是否会触发职责冲突」确认。

**审批人休假了，流程卡住**
让他"转办"给别人；或发起人取消后重新发起。

**审批通过了但业务状态没变**
到来源应用看该单据的状态说明；持续不同步就找管理员看该应用的"跨应用操作"页。

## 14.4 数据

**我的姓名/部门显示不对**
数据来自企业组织目录。找管理员改；如果公司从 LDAP/企业微信/钉钉同步，还要回源系统改，否则下次同步会覆盖。

**新同事在系统里搜不到**
组织目录里建好账号后，需要跑一次「主体投影同步」（企业控制台 → 目录同步），角色授权页才搜得到人。

**两个应用里的数据对不上**
每类数据有唯一的事实源，以事实源为准：

| 数据 | 事实源 |
| --- | --- |
| 部门、人员、项目注册 | 企业控制台 目录 |
| 客户、商机、合同、回款计划 | Altoc |
| 项目执行、里程碑、工时 | Aims |
| 文档正文 | Codocs |
| 发票、到账、核销 | Finance |
| 资产、环境、交付视图 | Assets |
| 员工事实、任职、成本快照 | People |

对不上通常是同步延迟或某次跨应用操作失败。让管理员看目标应用的「跨应用操作」页。

**文档找不到了**
1. 先看回收站
2. 用全文搜索搜标题关键词
3. 可能是别人移动了空间，或你对新空间没权限

## 14.5 性能

**系统很慢**
让管理员看企业工作台的「访问观测」，能看出是全局慢还是某个页面慢，以及是前端还是接口的问题。

**列表加载很久**
先收窄筛选条件。如果筛选后仍然慢，报给管理员，带上具体页面和筛选条件。

## 14.6 给管理员：升级到汇智云支持前先做这些

- [ ] 用「检查员工是否有某项权限」确认不是权限问题
- [ ] 看企业工作台有无告警
- [ ] 看部署连通性与订阅/License 状态
- [ ] 看目标应用的「跨应用操作」页有无失败记录
- [ ] 看企业控制台「日志管理」有无相关操作记录
- [ ] 确认是个例还是全员

**提交问题时带上**：
企业名称/租户编码、出问题的应用、发生时间、具体操作路径、涉及的员工标识、完整错误信息或截图、已排查的步骤。

信息越全，解决越快。
