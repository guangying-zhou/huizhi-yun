# 06 员工门户与审批

**读者**：全体员工

不管你用哪个应用，需要你处理的事都会汇聚到两个地方：**我的待办**和**通知**。审批则统一由 Workflow 处理。

## 6.1 我的待办

**入口**：企业控制台 → 我的待办

汇总所有应用产生的、需要你处理的事项：待审批的单据、待确认的信息、待办任务。

**怎么用：**

- 点击事项直接跳到来源业务页面处理。
- 已读和归档**不会**改变待办状态——事项会在来源业务完成后自动关闭。所以点了"已读"但事没办，它还在。
- 事项显示来源应用，方便你判断优先级。

> 常见误解："我把它标记已读了怎么还在？" 因为待办的关闭条件是业务办完，不是你看过了。

## 6.2 通知

**入口**：企业控制台 → 通知

系统和同事发给你的消息。与待办的区别：

| | 待办 | 通知 |
| --- | --- | --- |
| 需要你行动吗 | 是 | 不一定 |
| 什么时候消失 | 业务办完 | 你读了/归档 |
| 典型内容 | 待审批单据、待确认任务 | 状态变更提醒、@提及、系统公告 |

点进通知详情可以跳转到相关对象。

如果企业配置了企业微信或钉钉集成，重要通知也会推到 IM 里，不用一直盯着系统。

## 6.3 个人资料

**入口**：企业控制台 → 个人资料

查看你的姓名、工号、部门、职位、联系方式。

**信息不对怎么办**：这些数据来自企业组织目录，不在这里改。找企业管理员在目录里改；如果公司从 LDAP / 企业微信 / 钉钉同步组织数据，还要回到那个源系统改，否则下次同步会被覆盖。

## 6.4 审批：Workflow

汇智云所有应用的审批都走同一个引擎。你会用到三个页面：

| 页面 | 用途 |
| --- | --- |
| **汇智云流程**（首页） | 审批工作台总览 |
| **我的任务** | 分配给我、等我处理的审批任务 |
| **我发起的** | 我提交的流程实例及其进度 |

### 处理审批任务

在"我的任务"点开任务详情，可以执行的动作：

| 动作 | 说明 |
| --- | --- |
| **通过** | 同意，流程进入下一节点 |
| **驳回** | 不同意，退回 |
| **转办** | 转给别人处理（自己确实不该审的时候用） |

**只有任务分配给你、且状态为待处理时**才能操作。别人的任务你看得到但点不了，这是正常的。

**建议**：驳回时一定写清楚原因。发起人只能看到你填的意见，写"不同意"三个字等于让他重猜一遍。

### 跟踪自己发起的流程

在"我发起的"里查看流程实例：

- 当前走到哪个节点、卡在谁那里
- 完整的审批历史与意见
- 可执行的动作：**取消**（撤回还没走完的流程）、**重新提交**（被驳回后改好再走一遍）

**流程卡住了怎么办**：先看当前节点的处理人是谁，直接找他；如果他不该审（休假、转岗），让他"转办"，或者你取消后重新发起。

## 6.5 审批从哪里发起

审批不在 Workflow 里发起，而是在**业务应用里**发起。举例：

| 你要做的事 | 在哪发起 |
| --- | --- |
| 报销一笔费用 | Finance → 费用报销 |
| 申请开票 | Altoc 回款计划 或 Finance → 开票申请 |
| 申请领用一台笔记本 | Assets → 资产操作 |
| 提交采购申请 | Assets → 采购单 |
| 项目立项 / 验收 | Aims → 项目 |
| 文档发布审阅 | Codocs → 审阅中心 |
| 任职变更 / 绩效确认 | People |

发起后，任务自动出现在审批人的"我的任务"和"我的待办"里。

## 6.6 审批流程配置（管理员）

以下页面需要 `workflow:designer` 或 `workflow:admin` 角色：

| 页面 | 管什么 |
| --- | --- |
| 流程定义管理 | 审批流程的节点与流转规则 |
| 表单定义管理 | 审批表单的字段 |
| 审批业务管理 | 哪些业务动作需要走审批 |
| 路由规则管理 | 按条件路由到不同审批人 |

**改流程定义前注意**：进行中的流程实例会按发起时的定义继续走，改动只影响新发起的流程。所以改完不用担心在途单据错乱，但也不要指望改动能修复已经走错的单据。

> `workflow:admin`（流程管理员）默认**不包含**业务审批、撤回或重新提交动作。管理流程配置和实际审批是两件事，需要分别授权。

## 6.7 常见问题

**待办里的事项点不开**
可能你对来源业务对象没有权限。找管理员按 [05 章 5.9](./05-角色与权限管理.md#59-排查流程) 排查。

**该我审的单子没出现在"我的任务"里**
1. 确认流程真的走到了你这个节点（让发起人在"我发起的"里看）
2. 确认你有 `workflow:approver` 角色
3. 确认审批路由规则指向的是你

**我能看到任务但按钮是灰的**
任务不是分配给你的，或者状态不是"待处理"（可能已被别人处理或已撤回）。

**审批通过了但业务状态没变**
业务侧可能还有后续动作没完成。到来源应用看该单据的状态说明。持续不同步就联系管理员。

**为什么我不能审批这张单子？**
可能命中了职责冲突规则（比如你是提交人，不能自己审自己）。让管理员用"检查单据是否会触发职责冲突"确认（见 [05 章 5.5](./05-角色与权限管理.md#55-两个诊断工具)）。
