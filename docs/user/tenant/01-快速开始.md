# 01 快速开始

## 1.1 汇智云是什么

汇智云把研发项目、协作文档、销售经营、财务、资产、人员这几件事放进同一套组织目录和权限体系。你在一个地方登录，就能进入被授权的所有应用，部门和人员信息全公司只维护一份。

## 1.2 你会用到的应用

| 应用 | 干什么用 | 典型使用者 |
| --- | --- | --- |
| **企业控制台 Console** | 企业配置、组织目录、集成、凭证 | 企业管理员 |
| **Codocs 文档** | 写文档、多人协同、知识沉淀 | 全员 |
| **Aims 项目** | 项目、需求、迭代、看板、工时 | 项目经理、产品、开发、测试 |
| **Altoc 经营** | 客户、线索、商机、报价、合同、回款 | 销售、客户成功 |
| **Finance 财务** | 发票、收款、核销、费用报销 | 财务、全员报销 |
| **Assets 资产** | 电脑设备、软件订阅、采购、领用归还 | 行政、采购、全员 |
| **People 人员** | 员工档案、任职、绩效周期 | HR、部门负责人、员工自助 |
| **Insights 研发效能** | 代码贡献与效能分析 | 技术管理者 |
| **Workflow 审批** | 各应用的审批任务都汇聚在这里 | 全员 |

看不到某个应用有两种原因：公司没买，或者没给你授权。找企业管理员确认。

## 1.3 首次登录

1. 打开企业管理员发给你的地址，用公司账号登录。
2. 如果公司接入了企业微信 / 钉钉 / 企业统一登录，直接用对应方式登录，不需要单独记密码。
3. 首次登录后建议先去**个人资料**确认姓名、部门、联系方式是否正确。信息不对找企业管理员在目录里改，不是在应用里改。

## 1.4 在应用之间切换

汇智云用**企业 Shell** 统一切换应用：左侧或顶部有应用启动器（AppLauncher），点一下就能换应用，不用记各个应用的网址，也不用重复登录。

- 应用列表只显示**你被授权的应用**。
- 切换应用不会丢失登录状态。
- 如果某个应用在不同域名下部署，可能会打开新标签页，这是正常的。

## 1.5 看懂界面

汇智云所有应用遵循同一套界面约定，学会一次到处适用：

**列表页**
- 顶部是筛选和搜索。搜索是服务端搜索，输入后稍等即可，不用点按钮；按回车立即搜。
- 列表底部是分页，显示"共 N 条"。改任何筛选条件都会回到第 1 页。
- 表格为空时会显示说明和下一步建议，不是出错。

**状态颜色**
| 颜色 | 含义 |
| --- | --- |
| 绿色 | 正常、已完成、已生效 |
| 黄色 | 待处理、警告、需要注意 |
| 红色 | 失败、已拒绝、已过期 |
| 灰色 | 未启用、草稿、已归档 |

**危险操作**
删除、停用、覆盖这类操作会弹确认框，写明对象名和后果。红色调=不可恢复，黄色调=可恢复。看清楚再点。

**创建/编辑**
- 字段少的对象在弹窗或侧边抽屉里填。
- 字段多、有明细或分步骤的对象会打开独立页面。

## 1.6 我的待办和通知

企业控制台有两个全局入口：

- **我的待办** — 需要你处理的事：审批任务、待确认的信息、待办事项。
- **通知** — 系统和同事发给你的消息。

各应用产生的审批任务都会汇聚到这里，不用一个个应用去翻。详见 [06 员工门户与审批](./06-员工门户与审批.md)。

## 1.7 遇到问题先看这里

| 现象 | 先做什么 |
| --- | --- |
| 看不到某个应用 | 找企业管理员确认是否已授权 |
| 进了应用但页面 403 | 缺角色或数据范围，找管理员 |
| 看不到某个部门/项目的数据 | 数据范围没覆盖，找管理员 |
| 能看但不能审批/导出 | 敏感动作需要单独授权，找管理员 |
| 人员信息不对 | 找管理员在企业控制台的目录里改 |

更多见 [14 常见问题](./14-常见问题.md)。
