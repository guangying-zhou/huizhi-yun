# 09 Altoc 经营

**做什么**：LTC（Lead to Cash）经营管理——从线索到回款的全流程。
**谁在用**：销售、客户成功、合同管理、经营管理者。
**适合**：ToB / ToG 项目型企业（IT 服务商、系统集成商、方案型销售团队）。

## 9.1 菜单结构

| 分组 | 页面 |
| --- | --- |
| **首页** | 经营概览 |
| **销售管理** | 线索、客户、商机 |
| **商务管理** | 报价、投标、合同、回款 |
| **数据分析** | 经营看板 |
| **跨应用操作** | 跨应用动作执行状态 |
| **设置** | 基础配置、团队管理、个人设置 |

## 9.2 主线：线索 → 回款

```
线索 Lead
  ↓ 转化
客户 Customer  +  商机 Opportunity
  ↓
报价 Quotation  /  投标 Tender
  ↓ 赢单
合同 Contract
  ↓ 生效（自动编排）
交付项目（Aims）
  ↓ 里程碑验收
回款计划推进到「可开票」
  ↓
开票申请（Finance）→ 发票 → 到账 → 核销
  ↓
合同财务摘要回写 Altoc
```

**这条链是自动打通的。** 合同生效会自动在 Aims 建交付项目并同步里程碑；Aims 验收里程碑完成会自动推进回款计划；Finance 核销后会自动回写合同的已收/未收金额。你不需要在三个系统里重复录入。

## 9.3 常见操作

### 线索与客户

- **线索**：初步接触的机会，信息不全也可以先建。跟进后转化为客户 + 商机。
- **客户**：正式客户档案，含联系人。`customer_code` 是跨应用的客户标识，Aims、Assets、Finance 都引用它。

### 商机

商机是销售漏斗的核心对象。维护：金额、阶段、预计签约时间、负责人、竞争情况。

**商机负责人**用的是动态关系授权——你是某个商机的负责人，就自动有这个商机的权限，不需要单独配角色。

### 报价与投标

- **报价**支持多版本。改价格建新版本，不要覆盖旧版本，否则谈判过程无法追溯。
- **投标**管理招投标过程材料与节点。

报价、合同、折扣、商务条款和关键回款节点的审批由 `altoc:contract_approver`（合同审批人）处理。

### 合同

合同是经营侧的关键对象，包含：合同行、履约义务、付款条款、回款计划。

**合同生效时会触发履约启动**，按合同行的项目策略自动编排：

- 在 Aims 创建一个或多个交付项目（一个合同可以拆成多个项目）
- 把付款条款同步为项目的 PIVR 里程碑
- 如果涉及客户交付资产，同步到 Assets 建立客户交付资产主档

也可以把**已有的** Aims 项目关联到合同——在合同详情页选择可关联的项目即可。

### 回款

回款计划按付款条款生成。状态推进：

| 状态 | 什么时候变成这个状态 |
| --- | --- |
| 待触发 | 合同生效，条件未满足 |
| 可开票 | Aims 对应验收里程碑完成 |
| 已开票 | Finance 开出发票 |
| 已收款 | Finance 确认到账并核销 |

**在回款计划上直接发起开票申请**，申请会进入 Finance 并触发审批。不用切到 Finance 手工录一遍。

### 经营看板

数据分析 → 经营看板：漏斗、签约、回款、客户等经营指标。

## 9.4 跨应用协同

| 方向 | 内容 |
| --- | --- |
| **Altoc → Aims** | 合同生效创建交付项目、同步付款条款为里程碑 |
| **Aims → Altoc** | 验收里程碑完成，推进回款计划到"可开票" |
| **Altoc → Finance** | 从回款计划发起开票申请 |
| **Finance → Altoc** | 核销后回写合同财务摘要（已收/未收/状态） |
| **Altoc → Assets** | 履约启动时同步客户交付资产计划 |
| **Assets → Altoc** | 交付资产状态变更（已交付/上线/已验收）回写合同计划资产；验收会推进履约义务并让结算计划可结算 |
| **Altoc ↔ Codocs** | 客户、商机、合同相关文档 |

**跨应用操作**页可以看到这些动作的执行状态。失败时能看到具体原因，不用猜。

## 9.5 角色一览

| 角色 | 能做什么 |
| --- | --- |
| `altoc:viewer` | 查看与自己相关的客户、商机、合同和回款 |
| `altoc:sales` | 维护客户、线索、商机、报价与招投标过程 |
| `altoc:customer_success` | 维护维保合同、SLA、服务工单和续约经营机会 |
| `altoc:contract_manager` | 管理合同与回款，推进签订和履约跟踪 |
| `altoc:contract_approver` | 审批报价、合同、折扣、商务条款和关键回款节点 |
| `altoc:admin` | 管理经营模块全部配置与历史数据 |

> 销售（`altoc:sales`）**不含**合同审批权。审批要单独给 `altoc:contract_approver`，且不应该给同一个人——这是职责冲突控制。

## 9.6 使用建议

1. **商机阶段如实更新。** 漏斗数据失真，经营看板就没意义。
2. **报价改版本不改原件。** 谈判过程要能追溯。
3. **合同的付款条款认真填。** 它决定了 Aims 的里程碑和回款计划，填错了两边都要返工。
4. **别在 Altoc 里记项目执行进度。** 那是 Aims 的事，两边记会对不上。
5. **别在 Altoc 里算财务。** 发票、到账、核销以 Finance 为准。
