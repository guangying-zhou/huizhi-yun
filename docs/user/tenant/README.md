## 三句话理解汇智云

1. **一套组织，多个应用。** 部门、人员、项目只在企业控制台维护一次，所有应用共用。
2. **角色定义能做什么，数据范围定义能对哪些对象做。** 两者缺一不可。
3. **跨应用是打通的。** 商机→合同→交付项目→文档→发票→回款是一条线，不用重复录入。
