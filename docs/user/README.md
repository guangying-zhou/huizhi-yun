# 汇智云用户文档

面向**使用者**的操作手册。开发与架构文档仍在 `docs/` 根目录，两者互不覆盖。

| 目录 | 读者 | 内容 |
| --- | --- | --- |
| [`platform/`](./platform/README.md) | 汇智云平台运营方 | 应用接入、订阅计划、租户开通、部署诊断、运营支持 |
| [`tenant/`](./tenant/README.md) | 购买汇智云的企业 | 企业开通、控制台配置、组织目录、角色授权、各业务应用使用 |

## 先分清三个"端"

汇智云有三层界面，手册按这三层组织，不要混淆：

| 端 | 谁在用 | 入口 | 手册 |
| --- | --- | --- | --- |
| **运营控制台** `/admin` | 汇智云运营人员 | Platform（端口 3011） | `platform/` |
| **企业工作台** `/dashboard` | 企业的平台管理员 | Platform（端口 3011） | `tenant/` 第 02 篇 |
| **企业控制台 + 业务应用** | 企业管理员与全体员工 | Console（3000）及各应用 | `tenant/` 第 03 篇起 |

同一个企业管理员会同时用到 `/dashboard` 和 Console：前者管"买了什么、部署在哪、谁能用哪个应用"，后者管"企业内部怎么配置、组织目录、集成与凭证"。

## 文档约定

- 所有菜单名、角色名、资源名取自各应用的 `app.manifest.json` 与导航配置，与界面一致。
- 标注 🟡 的功能处于开发中，界面可能与描述有出入。
- 涉及命令行、SQL、部署脚本的内容不在本手册，见 `docs/` 根目录对应运维文档。
