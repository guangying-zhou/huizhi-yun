# DEBUG REPORT — Directory Connector Console token 403

- **Symptom:** `hzy-data-runtime-directory.service` repeatedly restarted and logged `register directory connector: Console token endpoint returned HTTP 403` after the connector private-key ownership had been corrected.
- **Root cause:** The credential and all three grants were valid in production. `auth_token_events` recorded `Trusted service-token source binding is invalid.` for the connector client. The generated installer configured `HZY_DIRECTORY_CONNECTOR_CONSOLE_URL` with the tenant root URL. Tenant Gateway therefore proxied `/oauth/token` through the default Console route and injected trusted `x-hzy-app-code=console`, while the authenticated service client is bound to `app_code=directory-connector`. Console correctly rejected that trusted-source mismatch during service JWT signing.
- **Fix:** Added an allowlisted `/directory-connector` Tenant Gateway proxy that strips the prefix before forwarding to Console, removes cookies, preserves trusted tenant/deployment context, and injects `x-hzy-app-code=directory-connector`. Updated Platform install-command generation to use the prefixed base URL. Arbitrary Console paths under the prefix continue through the normal Console route and do not receive the connector source identity.
- **Evidence:** Production DB inspection showed one active connector client, one active credential, and active `configure`, `execute`, and `sync` grants; failed token events all carried the trusted-source-binding error. Gateway tests passed 14/14; Platform tests passed 192/192; Platform lint, typecheck, test, Cloudflare build, and dry-run passed. After deployment, a sanitized request to `https://wiztek.huizhi.yun/directory-connector/oauth/token` reached Console as `/oauth/token` and returned the expected `401 invalid_client` for deliberately invalid credentials instead of a routing/source-binding failure. Platform `/api/health` returned 200.
- **Regression test:** `deploy/cloudflare/tenant-gateway/test/routing-context.test.mjs` verifies trusted connector source binding, tenant/deployment injection, cookie removal, prefix stripping, and denial of arbitrary connector-source routes. `platform/test/tenantRuntimeEnrollmentContract.test.ts` verifies generated commands use `/directory-connector`.
- **Deployment:** Tenant Gateway version `35c40a8e-9560-432d-ae14-ae10ddc84e1f`; Platform version `39e8b057-51e0-4c59-89bd-e87ef18e8ff6`.
- **Related:** Existing installations retain their prior `HZY_DIRECTORY_CONNECTOR_CONSOLE_URL`; they must rerun the newly generated install command or update only that environment value and restart the connector service. Existing client credentials do not need rotation or re-enrollment.
- **Status:** DONE_WITH_CONCERNS — code and Cloudflare deployments are verified; final successful token issuance requires the existing server to adopt the new prefixed URL.
